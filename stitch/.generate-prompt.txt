# sayac-33213 — Basit Sayıcı Uygulaması PRD

## 1. Genel Bakış

sayac-33213, kullanıcıların bir sayıyı artırma, azaltma ve sıfırlama işlemlerini yapabilecekleri basit bir web sayıcı uygulamasıdır. Uygulama React 18 + Vite + Tailwind CSS ile geliştirilmiş tek sayfalık bir SPA'dır (Single Page Application). Sayı değeri localStorage üzerinde kalıcı olarak saklanır, böylece sayfa yenilense bile son değer korunur. Son 5 adım history listesi kullanıcıya geçmiş işlemleri gösterir. Türkçe arayüzlü, minimalist ve erişilebilir bir deneyim sunar.

Hedef kitle: Günlük hayatta basit sayma/sayı takibi yapmak isteyen herkes. Örnek kullanım senaryoları: günlük su tüketimi sayacı, spor tekrar sayacı, stok takibi, basit anket sayacı.

## 2. Hedefler

2.1 Kullanıcı sayıyı +1 artırabilmeli ve bu anlık olarak ekranda görünmeli.
2.2 Kullanıcı sayıyı -1 azaltabilmeli, negatif değerler desteklenmeli.
2.3 Kullanıcı sayıyı sıfırlayabilmeli (0'a geri getirmeli).
2.4 Sayı değeri tarayıcıda localStorage ile kalıcı olmalı, yenileme sonrası korunmalı.
2.5 Son 5 işlem (artırma/azaltma/sıfırlama) history listesinde görünmeli.
2.6 Tüm arayüz metinleri Türkçe olmalı.
2.7 Mobil uyumlu (responsive) tasarım, 320px – 1920px arası tüm ekranlarda düzgün görünmeli.
2.8 Erişilebilir tasarım: klavye navigasyonu, ARIA etiketleri, yeterli kontrast oranı.

## 3. Tech Stack Detayı

Framework: React 18.2 (fonksiyonel bileşenler + hooks)
Build Tool: Vite 5.x — hızlı geliştirme sunucusu ve üretim build'i
Styling: Tailwind CSS 3.x — utility-first CSS yaklaşımı, responsive grid/flexbox
State Management: React useState + useEffect (yerel state, harici state kütüphanesi gerektirmez)
Local Storage: Browser localStorage API — sayı değeri ve history JSON string olarak saklanır
Routing: Yok (tek sayfa, routing gerektirmez)
Icon Library: Lucide React — Arttır (+), Azalt (-), Sıfırla (RotateCcw) ikonları
TypeScript: Evet, tam TypeScript projesi

## 4. Fonksiyonel Gereksinimler

### 4.1 Sayı Gösterimi
- Ekranda büyük, okunaklı bir şekilde mevcut sayı değeri gösterilir
- Sayı ortalanmış, büyük font boyutu (text-6xl veya üzeri)
- Negatif sayılar desteklenir (eksi işareti ile gösterilir)
- Binlik ayracı yok (basitlik için sadece rakam)

### 4.2 Arttırma Butonu
- Etiket: "Arttır" (+ ikonu ile birlikte)
- Tıklama: mevcut değer +1 artar
- Başarı durumu: ekrandaki sayı güncellenir, history'ye "+1" satırı eklenir
- Erişilebilirlik: aria-label="Sayıyı 1 artır", role="button", keyboard focus destekli

### 4.3 Azaltma Butonu
- Etiket: "Azalt" (- ikonu ile birlikte)
- Tıklama: mevcut değer -1 azalır
- Başarı durumu: ekrandaki sayı güncellenir, history'ye "-1" satırı eklenir
- Erişilebilirlik: aria-label="Sayıyı 1 azalt", role="button", keyboard focus destekli

### 4.4 Sıfırla Butonu
- Etiket: "Sıfırla" (RotateCcw ikonu ile birlikte)
- Tıklama: değer 0'a döner
- Tarih: "0" değerine sıfırlandığında history'ye "↺ 0" satırı eklenir
- Erişilebilirlik: aria-label="Sayacı sıfırla", onay gerektirmez (hızlı işlem)

### 4.5 localStorage Kalıcılığı
- Her state değişikliğinde (artırma, azaltma, sıfırlama) otomatik olarak localStorage'a kayıt yapılır
- Key: "sayac_value" — sayı değeri (number, JSON.stringify ile saklanır)
- Key: "sayac_history" — history dizisi (JSON array, max 5 item, en yeni en üstte)
- Sayfa yüklendiğinde localStorage'dan değer okunur, yoksa 0 başlangıç değeri kullanılır
- localStorage hatası (quota exceeded, private mode): sessizce devam et, hata gösterme

### 4.6 History Listesi
- Son 5 işlem sıralı liste (en yeni en üstte)
- Her satırda: zaman damgası (HH:mm:ss formatında) + işlem tipi + yeni değer
- Format örneği: "14:23:01  +1  →  5"
- History boşken boş bir liste gösterilir, "Henüz işlem yapılmadı" mesajı ile
- Max 5 kayıt tutulur, 6. işlem eklendiğinde en eski silinir (FIFO)

### 4.7 Hata Mesajları ve Boş Durumlar
- History boş: "Henüz işlem yapılmadı" (text-gray-400, italic)
- localStorage okuma hatası: sessizce 0 ile başla, console.error ile logla
- localStorage yazma hatası: sessizce devam et

## 5. Veri Modeli

### Entity: Counter
```typescript
interface Counter {
  value: number;        // Mevcut sayı değeri, negatif desteklenir
  updatedAt: string;     // ISO 8601 zaman damgası, son güncelleme
}
```

### Entity: HistoryEntry
```typescript
interface HistoryEntry {
  id: string;            // Benzersiz ID (timestamp + random)
  operation: '+1' | '-1' | '↺';  // Yapılan işlem
  previousValue: number; // İşlem öncesi değer
  newValue: number;      // İşlem sonrası değer
  timestamp: string;     // HH:mm:ss formatında zaman
}
```

### localStorage Keys
| Key | Type | Açıklama |
|-----|------|----------|
| sayac_value | number | Mevcut sayaç değeri |
| sayac_history | HistoryEntry[] | Son 5 işlem (JSON array) |

## 7. Non-Functional Requirements

### 7.1 Performans
- İlk yükleme: < 1 saniye (Vite hızlı build, minimal bundle)
- Sayı güncelleme: < 16ms (60fps, React re-render süresi)
- localStorage yazma: async, UI'ı bloklamaz
- Bundle size hedefi: < 100KB gzipped (React + Tailwind base)

### 7.2 Erişilebilirlik (WCAG 2.1 AA)
- Tüm butonlarda aria-label mevcut
- role="button" tüm butonlarda
- Klavye: Tab ile navigasyon, Enter/Space ile tıklama
- Focus indicator: ring-2, tüm interactive elementlerde görünür
- Kontrast: sayı değeri text-primary (#1E293B) on Surface (#FFFFFF) = ~15:1
- Touch hedefleri: minimum 48x48px
- Ekran okuyucu: ARIA live region ile sayı değeri duyurulur (aria-live="polite")

### 7.3 Tarayıcı Desteği
- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- iOS Safari 14+, Android Chrome 90+
- Responsive: mobile 320px → tablet 768px → desktop 1920px
- Flexbox + CSS Grid (Tailwind defaults)

### 7.4 Browser State Management
```typescript
window.app = {
  state: 'idle' | 'loading' | 'error',
  counter: { value: number, history: HistoryEntry[] },
  actions: { increment, decrement, reset }
}
```
